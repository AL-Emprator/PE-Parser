# PE-Parser
PE-Parser in C zum Analysieren von Windows-EXE- und DLL-Dateien. Liest PE32/PE32+-Header, Sektionen und Datenverzeichnisse und rechnet RVAs in Dateioffsets um.

# PE-Parser

Ein kleines Lernprojekt in C zum Lesen und Untersuchen von Windows-Dateien im Portable-Executable-Format (PE), zum Beispiel `.exe` und `.dll`. Das Programm führt die untersuchte Datei nicht aus.
